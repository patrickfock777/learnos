# LearnOS

Deine persönliche Englisch-Lernplattform.

## Setup

1. Supabase SQL ausführen (supabase-schema.sql)
2. .env.local ausfüllen
3. `npm install && npm run dev`

## Features
- Bibliothek: Texte lesen, anhören, KI-Verbesserung
- Vokabel-Trainer: Sets, Karten, lokaler Quiz
- Schreib-Trainer: Texte + KI-Feedback + Verlauf
- Grammatik-Trainer: Zeitformen erkennen
